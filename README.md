## ✨ Key Features / 主要特性

🌍 **Multilingual Support** - Automatic language detection & manual switching (Chinese/English)  
🌍 **多语言支持** - 自动语言检测和手动切换（中文/英文）

🎨 **Modern Interface** - Built with CustomTkinter, dark mode support  
🎨 **现代化界面** - 基于 CustomTkinter，支持深色模式

🖱️ **Drag & Drop** - Drag files directly to the window  
🖱️ **拖拽支持** - 直接拖拽文件到窗口

⚙️ **Visual Configuration** - Configure all clinker parameters graphically  
⚙️ **可视化配置** - 图形化配置所有 clinker 参数

📊 **Real-time Log** - Display running process without freezing  
📊 **实时日志** - 显示运行过程不卡顿

🌐 **Path Compatible** - Handles Windows paths with spaces and Chinese characters  
🌐 **路径兼容** - 完美处理 Windows 路径空格和中文

## 🚀 Quick Start / 快速开始

### Installation / 安装

```bash
# Clone repository / 克隆仓库
git clone https://github.com/yourusername/clinker-gui.git
cd clinker-gui

# Install dependencies / 安装依赖
pip install -r requirements.txt

# Run / 运行
python clinker_gui.py
```

Or simply double-click `ClinkerGUI.bat` (Windows)  
或者直接双击 `ClinkerGUI.bat` (Windows)

## 🛠️ Prerequisites / 前置条件

### 1. Install Python / 安装 Python
Download from: https://www.python.org/downloads/  
下载地址：https://www.python.org/downloads/

### 2. Install Clinker / 安装 Clinker

**Option A (npm):**
```bash
npm install -g clinker
```

**Option B (pip):**
```bash
pip install clinker-py
```

### 3. Install GUI Dependencies / 安装 GUI 依赖
```bash
pip install -r requirements.txt
```
